# RFX — Request for Anything

A Vista Site Selection concept tool for streamlining the RFI/RFP process.

**Live demo:** https://mrwhfloydiv.github.io/vista-rfx/

## What it does

RFX works in three stages:

1. **Lift** — drop in any RFI or RFP (Word, PDF, Excel, email) and RFX reads it, extracting every requirement, deadline, and evaluation criterion into a structured checklist.
2. **Match** — each requirement is checked against a maintained answer library: green means auto-fill ready, gold means a library draft needs tailoring, blue means it genuinely needs expert input.
3. **Land** — send the results where they need to go: a response draft that mirrors the requester's own structure, a requirements tracker for Excel, or a comparison matrix when Vista is the one issuing the RFP.

## Status

**Phase 0 — clickable concept demo.** The two sample documents are real: a public Wisconsin County Forests Association RFP and an anonymized private-sector site selection RFP. Every requirement and status shown was lifted from actual project material.

Phase 1 connects live AI extraction so it works on any document you drop in — processed entirely on your own machine. No cloud storage, no client data leaving your laptop.
